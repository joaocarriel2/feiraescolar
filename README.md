# MARGEM — conhecimento em circulação

Projeto demonstrativo para feira escolar. A identidade e a experiência pública estão isoladas nesta pasta; nenhum arquivo do projeto original foi substituído.

## Estrutura

- `index.html`: ponto de entrada da experiência pública.
- `assets/css/site.css`: identidade visual, componentes e layout responsivo.
- `assets/js/app.js`: navegação, conteúdo demonstrativo, páginas de detalhe, busca e filtros.

Abra `index.html` em um navegador. A edição funciona sem dependências externas e pode ser publicada usando esta pasta como raiz.

Todo artigo, projeto e perfil atual é fictício e identificado como demonstração. As capas são ilustrações SVG originais, sem uso de fotos pessoais do projeto anterior. Não há login simulado, cadastro ativo ou credenciais externas nesta etapa.
